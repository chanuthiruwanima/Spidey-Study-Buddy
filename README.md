## SPIDEY: DESKTOP STUDY BUDDY
A spiderman-themed Tamagotchi and pomodoro timer.

# Features
- Pomodoro Timer
- Tamagotchi where you can give Spidey boba, watch him play basketball or let him sleep.
- Dialogue and encouragement along with some chaotic study advice
- Random Idle Behavior
- Interact with Spidey: Poke him by tapping him, or hover over him to pet him
- Toggle Tamagotchi/Pomodoro mode by clicking the spiderman icon
- Spotify Integration: Detects if music is being played and Spidey will listen to it with you

Made using Godot 4
